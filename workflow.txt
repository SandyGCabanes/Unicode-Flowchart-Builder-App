# HOW THE CONNECTING LINES GET DRAWN
```
------------------------------------------------------------------------
Regular step:                          Merge step (two sources):

   [ Source Step ]                      [ Source A ]     [ Source B ]
         |                                    \               /
         v  (Down)                             \             /
   [ New Step ]                                  \-----------/
                                                        |
   [ Source Step ] ----> [ New Step ]                  v
        (Right)                                   [ New Step ]

   [ New Step ] <---- [ Source Step ]
        (Left)

The app calculates the new box's position from the source + direction we
picked, then fills in the line between them with │ or ─ characters and caps
it with an arrowhead: ▼ down, ► right, ◄ left. A merge step draws a line
from each source down to a shared joint (┴), then one line onward to the
new box.
```

## Glossary

| Term | Full Name | What It Is |
|---|---|---|
| **Widget** | — | General term for any on-screen element we interact with — a catch-all covering text boxes, dropdowns, buttons, checkboxes, etc. When we see "Widget" alone in a diagram, it usually means a text field or display area that doesn't fit the more specific categories below. |
| **Radio** | Radio Button | A round selector where we pick exactly one option from a small group. Selecting one automatically deselects the others in that group. |
| **Combo** | Combobox / Dropdown | A field that shows one selected value but expands into a list of choices when clicked. Same thing as a "dropdown menu." |
| **Check** | Checkbox | A square box that toggles on/off independently of other checkboxes.  Unlike a radio button, checking one doesn't uncheck others.  Used only for the loop option. |
| **Button** | Push Button | A clickable control that triggers an action immediately when pressed (e.g., "Add Step," "Reset Flowchart"). |
